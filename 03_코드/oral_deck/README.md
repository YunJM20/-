# 구두발표 덱 생성 (v16 양식, 콩 vs 로메인 상추)
- `oral_a.py` : v16 템플릿(`026ddbb7-…v16.pptx`)에 add_slide.py로 환경·고찰②·참고문헌 슬라이드를 복제한 뒤 슬라이드별 내용·노트를 채우고, 제외 슬라이드를 삭제·재배열해 `구두발표_콩vs로메인상추_v1.pptx`를 만든다.
- `fig_recovery3.py` : 기공 회복비(침수·건조·복합, 콩·로메인). `fig_et.py` : 누적 관수량 + 작물·처리별 일일 증산량(로메인: 증산량·관수량 시트, 콩: 로드셀 mm×38.01 g/mm). `run_canopy.py` : 07_v13_review.py 4·5d 구간(로메인 캐노피). `fig_yield.py` : 생육·수확량 통합 그림.
- 일일 증산량(로메인) = 전날 관수 후 − 당일 관수 전 무게. 대조·침수는 증산량 시트, 건조·복합은 관수량 시트(연속일만).
