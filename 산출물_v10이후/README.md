# 산출물 (v10 이후 새로 만든 파일)

한국원예학회 구두발표(콩 vs 상추, 침수·건조·복합 스트레스) 작업 중 v10 이후 만든 슬라이드, 이미지, 코드, 데이터입니다.
P1 = DAT 1~10, P2 = 그 이후. Fv/Fm 이미지는 LI-600 야간 암적응 값 기준입니다.

## 데이터 (`데이터/`)

## 해석 시 주의
- gsw는 장비 보정값(PAR·기온 보정 없음)입니다. 그 밖의 LI-600 형광 지표는 PAR·기온 공변량 혼합모형 평균입니다.
- 콩 Fv/Fm은 9/28(LI-6800 측정)을 제외했고, P2는 DAT 29 하나뿐입니다.
- 콩 수확량은 종실 생체중 기준입니다.

- `이미지/et_daily_cloud.png`: 일별 증산량 그래프. 흐린 날은 회색 배경으로 표시했고(`fig_v18.py`), 콩은 로드셀, 상추는 반복 평균 ± SE입니다.
- 센서 이상으로 콩 대조구 DAT 40, 건조구 DAT 23·26 값을 제외했습니다 (`fig_v18.py`의 `BAD`). 슬라이드는 위에 일별 증산량, 아래에 누적 관수량 순서입니다.
- `이미지/bean_loadcell_vs_EC5.png`: 콩 일별 물 소모를 로드셀과 EC5 환산값으로 비교한 그림 (`fig_v19.py`). 제외 전 원자료 기준이라 이상값이 보입니다.

- 콩 로드셀 일별 관수량은 DAT 38에서 처리 간 값이 급변해(대조 764→233, 침수 651→971) 사용하지 않기로 했습니다. 7p 슬라이드는 일별 그래프 대신 처리 설계 타임라인(`이미지/design_timeline.png`, `코드/fig_v21.py`)으로 바꿨습니다. 콩 누적 관수량 막대(87%)와 요점 문구는 포트 라벨 확인 후 재검토가 필요합니다.

## 채소10_윤정민 수정 (8~10, 13~14p)
- `슬라이드/채소10_윤정민_수정.pptx`: 원본을 건드리지 않고 복사해서 수정한 파일입니다.
  - 8~10, 13~14p 그래프의 축 이름, 눈금, P1/P2, 유의성 문자를 1.2배로 키운 그림으로 교체했습니다. 범례는 그대로입니다.
  - 13, 14p 단계 블록(2.5 in)과 화살표(0.34 in)를 블록 사이 간격 0.5 in의 가운데에 놓아 서로 가리지 않게 했습니다.
  - 13, 14p의 gsw P2 막대 그림은 폭을 줄여(3.69→3.36 in) 옆 Φ 그래프의 y축 이름을 가리지 않게 했습니다.
- `채소10_수정/`: 교체한 그림, 생성 스크립트(`fig_big.py`는 글자 크기를 1.2배로 키워 다시 저장하는 래퍼), 편집 스크립트(`edit_ch10.py`).

- 13·14p: 총정리 그림을 기공(P2 막대), 명반응, 광합성 능력, 생육·수량 4개 그림으로 나눠 각각 위쪽 블록 중앙 아래에 배치했습니다 (`채소10_수정/{bean,lettuce}_{1_gsw,2_light,3_photo,4_growth}.png`, `fig_v23.py`). 블록 4개는 폭 2.5 in, 전체 0.92~12.48 in로 결론 박스·제목선과 같은 폭에 균등 배치했고, 화살표는 간격 중앙, 아래 라벨은 블록 중앙에 맞췄습니다.

- 11p 광합성 파라미터 그림: 상추 행의 x축 범위를 콩 행과 같게(0.4~4.6) 맞추고 y축 이름 위치를 고정해서 대조구가 y축에 붙던 문제를 고쳤습니다 (`채소10_수정/params_aligned.png`, `fo_figs.py`의 `params()`).

- 8p 관수 설계 그림: 건조는 DAT 3(침수 종료)부터 50% 관수로 시작하고 그 전까지는 대조구와 같은 양(100%)으로 수정했습니다 (`채소10_수정/design_timeline.png`, `fig_v21.py`). 결론 박스 문구와 축 눈금(상추 2일 간격)·글자 크기도 맞췄습니다.
