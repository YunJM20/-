# 산출물 (v10 이후 새로 만든 파일)

한국원예학회 구두발표(콩 vs 상추, 침수·건조·복합 스트레스) 작업 중 v10 이후 만든 슬라이드, 이미지, 코드, 데이터입니다.
P1 = DAT 1~10, P2 = 그 이후. Fv/Fm 이미지는 LI-600 야간 암적응 값 기준입니다.

## 슬라이드 (`슬라이드/`)
| 파일 | 내용 |
|---|---|
| `구두발표_콩vs로메인상추_v10.pptx` | 최신 전체 덱 22장. 4p·7p 통합, 5p·6p 순서 교체, 총정리 그래프 교체, 처리 전 데이터 제거 |
| `구두발표_8p_gsw_FvFm.pptx` | 8페이지 1장. 왼쪽 gsw, 오른쪽 Fv/Fm (각각 시계열·대조구 대비 %·구간별 표) |
| `구두발표_보충_P1P2_막대그래프.pptx` | LI-600 P1·P2 구간별 막대 그래프 보충 슬라이드 |
| `구두발표_보충_생육_전체지표.pptx` | 최종 생육조사 전체 지표 막대그래프 보충 3장 (발표 덱에는 미반영) |

## 이미지 (`이미지/`)
- `P1P2_막대/`
  - `P1P2_막대_gsw.png`, `P1P2_막대_명반응.png`: 처리별 평균 ± SE와 Tukey 문자, P1/P2 사이 점선.
  - `P1P2_대조구대비_gsw.png`, `P1P2_대조구대비_명반응.png`: 대조구 100% 기준, 대조구와 문자가 다르면 *.
  - `P1P2_막대_FvFm.png`, `P1P2_대조구대비_FvFm.png`: Fv/Fm 버전. y축을 0.80, 95%에서 잘랐습니다.
- `P2_gsw/`: `기공_P2_콩.png`, `기공_P2_상추.png`. v10의 12·13p 기공 그래프를 대체할 P2 전용 gsw 막대 (상추 y축 눈금 0.05).
- `FvFm_시계열/`: `fvfm_ts.png` (일별 시계열), `fvfm_rec.png` (대조구 대비 %).
- `v10_그림/`: v10에 들어간 그림. 환경 표용 `env`, gsw 시계열·대조구 대비, ΦPSII·ΦNPQ·ΦNO 통합 `phi3`, 총정리 `recap2/3`.
- `생육/`: 생육 전체 지표 막대그래프 (콩 2장, 상추 1장).

## 코드 (`코드/`)
| 파일 | 역할 |
|---|---|
| `fig_v13.py` | P1/P2 막대 (gsw, ΦPSII, ΦNPQ, ΦNO) |
| `fig_v14.py` | 대조구 대비 % 막대 |
| `fig_v15.py` | P2 gsw 단독 막대 (콩, 상추) |
| `fig_v16.py` | Fv/Fm 시계열, 대조구 대비 % |
| `fig_v17.py` | Fv/Fm P1/P2 막대 (`fig_v13`/`fig_v14` 함수를 재사용) |
| `fvfm_calc.py` | Fv/Fm 일별 통계, 대조구 비율, 구간 모형(처리+측정일)과 Tukey 문자 |
| `edit_v10.py`, `edit_p8.py` | v9에서 v10을 만드는 편집, 8p 단독 슬라이드 조립 |
| `bars_build.py`, `growth_build.py` | 막대 보충 PPT, 생육 보충 PPT 조립 |
| `fig_v9.py`, `fig_v10.py`, `fig_v11.py`, `fig_v12.py` | v9~v10 그림 (환경, phi3, recap 등) |
| `fo_common.py`, `fo_figs.py`, `lib.py` | 공통 스타일, 그림 함수, pptx 편집 도우미 |

> 코드는 분석 작업공간(`an/`)의 `data/`, `intermediate/` CSV를 읽고, 환경변수 `ROM_DATA=<an/data 경로>`가 필요합니다.
> 그 작업공간은 이 저장소에 전부 들어 있지 않으므로 이 폴더만으로는 그림을 재생성할 수 없고, 코드는 방법 기록용입니다.

## 데이터 (`데이터/`)
- `fvfm_phase.csv`: Fv/Fm 구간별 원평균, Tukey 문자, P, 포함된 측정일.
- `daily_fvfm.csv`: 일별 평균, SE, n, 당일 ANOVA의 Holm 보정 P.
- `recovery_fvfm_{bean,lettuce}.csv`: 대조구 대비 %와 Welch t + Holm.
- `growth_final_panels.csv`: 생육 보충 그림용 값.

## 해석 시 주의
- gsw는 장비 보정값(PAR·기온 보정 없음)입니다. 그 밖의 LI-600 형광 지표는 PAR·기온 공변량 혼합모형 평균입니다.
- 콩 Fv/Fm은 9/28(LI-6800 측정)을 제외했고, P2는 DAT 29 하나뿐입니다.
- 콩 수확량은 종실 생체중 기준입니다.
